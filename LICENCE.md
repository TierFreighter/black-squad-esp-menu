## 🧩 About

**Black Squad ESP Menu** is a curated list of Black Squad open-source tools:

- **Overlays** — on-screen helpers, layout notes, radar view, HUD markers
- **Quality-of-Life Helpers** — config presets, menu notes, readability tweaks
- **Research Notes** — map layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Menu Hotkey — toggle the overlay window at any time
- Radar Notes — visualize map positions for study
- HUD Markers — label practice targets and routes
- Overlay Layout — adjustable panels and opacity

### Wallhack
- Config Presets — save and load overlay setups
- Color Themes — tune clarity for long sessions
- Font Scaling — improve readability on any display

### Aimbot
- Map Notes — segment study on each map
- Route Viewer — review paths in the overlay
- Session Log — record practice runs for review
